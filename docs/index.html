Bot de Laborin · Documentación

Chatbot de atención para **Laborin** con integración directa a la **Telegram Bot API** y un gateway HTTP para canales **web** y **móvil**. Vive íntegramente en esta carpeta (`/home/julian/Startup/Bot`): no modifica la landing, el backend ni el frontend. No usa dependencias de terceros: Node.js 18+ con `fetch` nativo y `node:test`. ---

Arquitectura

Telegram ──► fromTelegramUpdate ─┐
Landing  ──► fromWebPayload ─────┼──► bot.handleMessage ──► commands / messages / callbacks
App      ──► fromMobilePayload ──┘                         │
                                                          ├──► knowledge/answerEngine (respuesta única)
                                                          ├──► backendClient (datos opcionales)
                                                          └──► ChannelResponder ──► Telegram | outbox web | outbox móvil

Endpoints del gateway

MétodoRutaDescripción
GET/healthHealthcheck del gateway.
POST/telegram/webhookUpdates de Telegram, protegido por x-telegram-bot-api-secret-token.
POST/channels/webChat web: {sessionId, text, startParam?} → messages, con x-channel-token.
POST/channels/mobileChat móvil: {userId, text, role?, startParam?} → messages, con x-channel-token.

Solo se listan los nombres. Los valores reales viven en el .env del servidor y nunca en el repositorio.
